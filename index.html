SkullBitrage

SkullBitrage is an analytics platform that detects profit opportunities across decentralized crypto derivatives exchanges, focused on delta-neutral strategies and arbitrage, built with React and Node.js.

  • Periodic collection of market data per exchange (funding rates, prices, volume, and open interest)
  • Calculation of historical and real-time APRs using exponential moving averages (EMA) per token and exchange
  • Persistence of historical data in local files to ensure temporal consistency and multi-timeframe analysis

Marketplace

SkullMarketplace is a dApp that allows users to mint NFTs and view the NFTs in their wallet directly on the blockchain.

It’s built on Ethereum Sepolia, with smart contracts written in Solidity, decentralized storage on IPFS, and a frontend in React + TypeScript + Tailwind integrated with ethers.js, wagmi, and RainbowKit for wallet connection and on-chain interaction.

SkullRoulette

SkullRoulette is an interactive Web3 roulette game fully powered by smart contracts. Users can buy tokens, approve spending, and spin the roulette directly on-chain, with results generated and verified on Ethereum Sepolia. Built with Solidity, React, TypeScript, ethers.js, wagmi, and RainbowKit, Tailwind, the project showcases:

  • Secure ERC-20 token mechanics
  • On-chain betting logic
  • Event-driven UI updates
  • Responsive animated roulette interface
  • Clean Web3 wallet UX with real-time balance tracking
